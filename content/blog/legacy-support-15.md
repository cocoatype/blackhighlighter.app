---
title: "Legacy Support for iOS and macOS Versions"
date: "2024-06-02"
summary: 'Starting with Black Highlighter 24.1, some versions of Apple&apos;s operating systems are considered to be under "legacy support".'
---

Starting with Black Highlighter 24.1, some versions of Apple's operating systems (iOS/iPadOS 14.x and 15.x, and macOS 12.x) are considered to be under "legacy support". This means:

- Black Highlighter **will** still run on them, with the feature set that was originally supported.
- I will try my best to fix any reported bugs on these versions, but will not actively test or seek out bugs that affect these versions.
- New features **may** be backported to these versions, but may be available only to users on newer versions of iOS.

As a trade-off to these concessions, users who are running on legacy-support versions of iOS **get the features of Ultra Highlighter for free**.

Black Highlighter development is a one-man operation, and this structure allows me to continue to serve as many people as I can, while still being able to move quickly to support new features as easily as possible. Thank you for your understanding.
